# ZAドーナツ辞典

『Pokémon LEGENDS Z-A M次元ラッシュ』のドーナツ作り用の辞書ツールです。`index.html` をブラウザで開くだけで動きます（1ファイル完結）。

- **逆引き**: ついてほしいパワー（かがやき・オヤブン・どうぐ など）・パワーLv.・星の数・ハラモチ（kcal／腹持ち時間）・プラスLv. から、必要なきのみの組み合わせを探す
- **作る**: きのみを選んで、星・プラスLv.・ハラモチ・時間・つきやすいパワーを確認する。レシピの保存もできる
- **きのみ**: 通常33種＋いじげん33種の数値一覧。所持数を入れると手持ちだけで逆引きできる
- **パワー**: フレーバーパワーの効果と、数値ごとのLv.の出やすさ
- **設定**: 辞書の編集・追加とハラモチ消費速度の調整。公開ページ（Web版）ではオーナーにだけ表示され、変更は全員に反映されます。ダウンロード版では使う人が自分で管理でき、変更はその端末のブラウザに保存されます

## 対応環境

ブラウザで使うWebアプリです（インストール型アプリはありません）。対応ブラウザは **Chrome・Safari・Firefox** のみ。それ以外のブラウザでは未対応の案内が出ます。

## 辞書データの更新

辞書は全データ（きのみ66種・フレーバーパワー）が入った完成状態で配布しています。使う人が何かを追加する必要はありません。

- 公開ページ（Artifact）: 更新できるのはページのオーナーだけ。「設定」→「辞書の編集・追加」で数値の修正・きのみの追加をすると、全員に反映されます
- ダウンロード版（このリポジトリの `index.html`）: 使う人が各自で管理できます。「設定」で数値の修正・きのみの追加・消費速度の変更ができ、その端末のブラウザに保存されます（ほかの人には影響しません）。配布する初期データ自体を変えるときは `NAMES` / `NORMAL` / `HYPER` / `HTIER` / `POWERS` を編集してプッシュします

## 数値の出典と注意

- きのみの数値・パワー抽選: Serebii.net (Ansha's Donuts / Flavor Powers)
- 星の閾値と倍率: ポケモンWiki「ドーナツ」
- いじげんきのみの解放時期: Game8
- ハラモチの消費速度（kcal/秒）は攻略サイトの記載と実測報告からの目安です。「設定」で直せます
- 逆引きは「きのみ3種類まで」の組み合わせを調べます
