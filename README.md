# ZAドーナツ辞典

『Pokémon LEGENDS Z-A M次元ラッシュ』のドーナツ作り用の辞書ツールです。`index.html` をブラウザで開くだけで動きます（1ファイル完結）。

- **逆引き**: ついてほしいパワー（かがやき・オヤブン・どうぐ など）・パワーLv.・星の数・ハラモチ（kcal／腹持ち時間）・プラスLv. から、必要なきのみの組み合わせを探す
- **作る**: きのみを選んで、星・プラスLv.・ハラモチ・時間・つきやすいパワーを確認する。レシピの保存もできる
- **きのみ**: 通常33種＋いじげん33種の数値一覧。所持数を入れると手持ちだけで逆引きできる
- **パワー**: フレーバーパワーの効果と、数値ごとのLv.の出やすさ
- **設定**: 辞書の編集・追加とハラモチ消費速度の調整（表示される条件は下の表）

## 対応環境

ブラウザで使うWebアプリです（インストール型アプリはありません）。対応ブラウザは **Chrome・Safari・Firefox** のみ。それ以外のブラウザでは未対応の案内が出ます。

## 3つの使い方と、更新できる人

| 使い方 | 設定タブ | 辞書・消費速度を更新できる人 |
|---|---|---|
| 公開サイト（GitHub Pages: https://aoi0211.github.io/-ZA-/ ） | 出ない | リポジトリに書き込める人だけ。`index.html` のデータを編集してプッシュ |
| Claudeの公開ページ（Artifact） | オーナーにだけ出る | オーナーだけ。画面から更新すると全員に反映 |
| ダウンロード版（`index.html` をファイルとして開く） | 全員に出る | 使う人が各自で。その端末のブラウザにだけ保存 |

辞書は全データ（きのみ66種・フレーバーパワー）が入った完成状態で配布しています。使う人が何かを追加する必要はありません。配布データは `index.html` 内の `NAMES` / `NORMAL` / `HYPER` / `HTIER`（きのみ）、`POWERS`（パワー）、`DRAIN0`（消費速度）です。

## 公開サイトの設定

- GitHub の Settings → Pages で「Deploy from a branch」を選び、このブランチの `/ (root)` を指定
- 検索エンジン向けに、説明文・正規URL・構造化データ・`sitemap.xml` を入れてあります。Google Search Console にサイトを登録し、`sitemap.xml` を送信してください

## 数値の出典と注意

- きのみの数値・パワー抽選: Serebii.net (Ansha's Donuts / Flavor Powers)
- 星の閾値と倍率: ポケモンWiki「ドーナツ」
- いじげんきのみの解放時期: Game8
- ハラモチの消費速度（kcal/秒）は攻略サイトの記載と実測報告からの目安です。「設定」で直せます
- 逆引きは「きのみ3種類まで」の組み合わせを調べます
