# ZAドーナツ辞典

『Pokémon LEGENDS Z-A M次元ラッシュ』のドーナツ作り用の辞書ツールです。`index.html` をブラウザで開くだけで動きます（1ファイル完結）。

- **逆引き**: ほしい効果（フレーバー）・パワーLv.・星の数・ハラモチ（kcal／腹持ち時間）・プラスLv. から、必要なきのみの組み合わせを探す
- **作る**: きのみを選んで、星・プラスLv.・ハラモチ・時間・つきやすいパワーを確認する。レシピの保存もできる
- **きのみ**: 通常33種＋いじげん33種の数値一覧。所持数を入れると手持ちだけで逆引きできる
- **パワー**: フレーバーパワーの効果と、数値ごとのLv.の出やすさ
- **設定**: 辞書の編集・追加（管理者のみ）、ハラモチ消費速度の調整、データの書き出し・読み込み

## 対応環境

ブラウザで使うWebアプリです（インストール型アプリはありません）。対応ブラウザは **Chrome・Safari・Firefox** のみ。それ以外のブラウザでは未対応の案内が出ます。

## データをあとから足す

- 公開ページ（Artifact）から: オーナーと編集者だけが「設定」→「辞書の編集・追加」で数値の修正・きのみの追加ができ、全員に反映されます。それ以外の人は読み取り専用です
- `index.html` を単体で開いた場合は読み取り専用です
- ファイルで: `index.html` 内の `NAMES` / `NORMAL` / `HYPER` / `HTIER`（きのみ）、`POWERS`（パワー）を編集

## 数値の出典と注意

- きのみの数値・パワー抽選: Serebii.net (Ansha's Donuts / Flavor Powers)
- 星の閾値と倍率: ポケモンWiki「ドーナツ」
- いじげんきのみの解放時期: Game8
- ハラモチの消費速度（kcal/秒）は攻略サイトの記載と実測報告からの目安です。「設定」で直せます
- 逆引きは「きのみ3種類まで」の組み合わせを調べます
